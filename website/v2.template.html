Quick answers

Is it safe to let Moleui delete things?

Every module previews first and shows you the full list before anything changes. Deletions go to the macOS Trash, so they are recoverable, and protected paths like system roots, keychains, and credentials are refused even with admin rights.

What is free and what needs Moleui Pro?

The download is free and My Mac live monitoring is free forever. Cleanup, Optimize, Uninstall, and Storage analysis are part of Moleui Pro, a subscription you can start inside the app.

Is it really open source?

Yes. The engine and the app code are public on GitHub under the MIT license, so you can audit every line that touches your files.

What does it run on?

macOS, with native builds for both Apple Silicon and Intel. Releases are not notarized yet, so the first launch needs right-click and Open, and every release ships SHA256 checksums so you can verify your download.

How is this different from other Mac cleaners?

Most cleaners ask for trust. Moleui is built to not need it: open code, Trash-first deletions, previews before every action, and a rule that when uncertainty exists it refuses or asks instead of deleting more.
